# Airplane Battle

浏览器里就能玩的飞机大战。纯 HTML / CSS / JavaScript 实现，无构建、无依赖，打开页面即可开打。

## 玩法

敌机从上方不断落下。你需要操控战机射击它们，不让敌机冲出屏幕底部。生命值归零即游戏结束。

开局前可以先配装、再选难度：

| 类型 | 选项 | 效果 |
| --- | --- | --- |
| 子弹 | 普通 | 击中敌机后消失，重新装填 |
| 子弹 | 贯穿 | 击中后继续飞行，弹速更快 |
| 机身 | 普通 | 5 点生命，标准移速 |
| 机身 | 敏捷 | 3 点生命，移速更快 |
| 机身 | 重装 | 7 点生命，移速更慢，撞到敌机可将其击碎 |
| 难度 | 1 ~ 9 | 数字越大，场上敌机越多、刷新越快 |

默认难度为 **5**。配装和难度会在点击「开始游戏」时生效，对局中途切换不会立刻改变当前这一局。

## 操作

| 按键 | 作用 |
| --- | --- |
| `W` | 向上 |
| `A` | 向左 |
| `S` | 向下 |
| `D` | 向右 |
| 开始游戏 | 按当前配装与难度开一局 |

子弹会自动向上发射，无需手动开火。

## 快速开始

本仓库没有任何 npm / 构建步骤。任选一种方式即可：

```bash
git clone https://github.com/maoxiancat/Airplane-Battle.git
cd Airplane-Battle
```

然后用浏览器直接打开 `Airplane_Battle/index.html`。

如果本地打开时脚本被浏览器拦截，可以用任意静态服务器：

```bash
# Python 3
python3 -m http.server 8080
```

浏览器访问 `http://localhost:8080/Airplane_Battle/index.html`。

## 实现要点

- 战机、子弹、敌机的位置都用百分比表示，方便在固定战场内移动。
- 子弹与敌机用 `setInterval` 驱动：普通弹每 10ms 更新一次，贯穿弹每 5ms 更新一次；敌机每 100ms 下落一次。
- 难度同时影响「场上最多几架敌机」和「多久再刷一架」。
- 重装机身额外检测与敌机的碰撞，撞上即击碎对方。
- 敌机到达底部会扣 1 点生命；生命值 ≤ 0 时弹出「游戏结束」，并停止子弹与敌机循环。
